# part-2-cnn-computer-vision

This repository contains the implementation of a basic Convolutional Neural Network (CNN) model for solving an image classification problem using deep learning techniques.
The project includes:
Dataset exploration and analysis
Image preprocessing and augmentation
CNN model creation using TensorFlow/Keras
Model training and evaluation
Accuracy and loss visualization
Confusion matrix analysis
Sample prediction outputs
Explanation of important CNN concepts
Real-world business use case mapping
The objective of this project is to understand how CNNs learn visual patterns from images using convolution, activation functions, pooling layers, and dense layers.


Technologies Used:
Python
TensorFlow / Keras
NumPy
Pandas
Matplotlib
Scikit-learn
This project was developed as part of a Computer Vision and Deep Learning assignment focused on building a CNN-based image classification prototype.
